# TechConnect Hub

Build a conference app called TechConnect 2026. Tagline: "Discover sessions. Build your schedule. Meet your community."

Two views:

Session catalog — a list of session cards. Each card shows the session title, speaker name, time, room, and one or two topic tags. Include an "Add to Schedule" button on each card. Use about 12 realistic mock sessions on technical and leadership topics.

My Schedule — the sessions the user has added, sorted by time, showing title, speaker, and time.
